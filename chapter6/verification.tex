\section{独立几何与像素精度验证}
\subsection{参考模型与用例设计}
使用独立双精度软件模型实现与第~\ref{chap:algorithm}~章一致的坐标约定、
旋转顺序、畸变公式和边界规则。先比较坐标，再比较重采样及颜色量化，
分别定位参数量化、投影计算、最近邻阈值跳变和 RGB565 的误差来源。

用例至少覆盖零姿态、单轴与双轴边界、中间角度、限幅输入、无效深度、
图像末行/末列、非完整块、全黑块、容量等于上限和超出上限。
非零切向系数与后续 roll/双线性扩展应建立独立测试组。

已有分块渲染器测试使用另一个投影器实例生成坐标参考，主要证明调度、缓存及采样
与该投影器一致，不能单独作为独立浮点模型精度结论。

\subsection{控制与异常用例}
三个独立开关共有八种掩码，应覆盖 SOF 前后切换、pending、忙响应和无输入帧场景。
协议测试应包含错误 XOR、错误长度、半包超时和重同步。
DDR 测试应覆盖 AW/首拍同周期、1～16 beat、WREADY 停顿、错误 LAST、
最后写完成与下一帧调度相邻周期等情况，并检查异常时帧槽不会提前释放。

\section{实板测试步骤与记录模板}
\subsection{硬件链路及功能验收}
\begin{enumerate}
\item 记录硬件、软件、标定与位流版本，核对目标器件和位流哈希，连接电源、HDMI、IMU 与 CP2102。
\item 下载当前候选后确认初始化及视频时序，以固定图卡检查分辨率、颜色、首末像素和连续显示。
\item 验证八种开关组合、查询状态、LED 与 Gamma 遥测；分别记录 ACK、SOF 应用和画面切换时间。
\item 在标定图卡下测试零姿态、单轴、双轴和中间角度，记录安装方向、机械角度及输出结果。
\item 执行长时间运行、输入中断/恢复和连续姿态变化，保存帧序号、错误事件及视频。
\end{enumerate}

\subsection{帧率、延迟及画质测量}
帧率测试应在输入嵌入独立帧号或可追踪图案，统计完成矫正并输出的不同源帧，
避免将 60 Hz 扫描或重复帧计为 60 fps 处理。可使用逻辑分析仪、片内探针或采集视频，
记录输入 SOF、帧完成、结果发布和对应输出事件。

延迟可采用同一闪烁/触发事件的输入与输出对照，记录采集卡、显示设备或高速相机
引入的测量延迟。分别报告渲染时间和端到端时间，保留最小值、平均值、P95 及最大值。
画质测量使用真实棋盘格、倾斜边缘或网格线，保存无增强参考、增强结果及有效 ROI。
详细指标定义与待填表见第~\ref{chap:performance}~章。
